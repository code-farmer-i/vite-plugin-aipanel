# 使用指南

> 前置：已按「快速开始」完成插件安装、扩展加载，并保持 `vite dev` 运行、用 Chrome 打开 `localhost` 开发页面。

## 打开与关闭侧边栏

1. 点击浏览器工具栏中的 **AIPanel 图标**
2. 或按快捷键 **`Ctrl/Cmd + K`**（可在插件配置中自定义）

侧边栏打开后会自动连接当前项目的 AIPanel 服务，并恢复该项目上次的会话，直接在对话框中输入指令即可。

## 会话管理

会话列表位于面板左侧，可通过面板 Header 的 **会话列表** 按钮展开 / 收起：

- **自动复用** — 打开面板自动恢复当前项目最近的会话
- **新建会话** — 点击列表顶部的 **+** 创建新对话
- **切换会话** — 点击列表中的历史记录即可切换
- **删除会话** — 将鼠标悬停在会话条目上，点击条目右侧出现的 **×** 删除（需二次确认）

多个项目同时打开时，切换浏览器标签页会自动切换到对应项目的会话；会话标题由 AI 引擎自动生成，生成后实时同步到列表（无需刷新页面）。

## 页面上下文同步

打开面板后，以下信息自动实时同步给 AI：

| 信息       | 同步时机               |
| ---------- | ---------------------- |
| 页面 URL   | 页面加载、SPA 路由切换 |
| 页面标题   | `document.title` 变化  |
| 标签页切换 | 切换浏览器标签页时     |

无需手动描述当前在哪个页面，AI 自动知晓上下文。

## 元素选择器

想告诉 AI「改这个按钮的颜色」，不用描述它的位置，直接选中就行。

### 使用方法

1. 点击面板 Header 中的 **选择元素** 按钮（或按 `Ctrl/Cmd + P`）进入选择模式
2. 鼠标悬停时，页面元素会高亮显示
3. 点击目标元素，源码位置自动传给 AI 并注入对话框
4. 按 `ESC` 或再次按 `Ctrl/Cmd + P` 退出选择模式

### 传给 AI 的信息

- 组件源码文件路径与行号
- 元素文本内容
- 元素的 HTML 描述

AI 收到这些信息后可以直接定位到对应代码，精准修改。

**点击已选节点**（右侧「已选节点」列表、页面上的气泡，或 dsh 对话框里的节点 chip）会跳回它被选中时的页面，并在页面上以呼吸灯效果高亮该元素——元素在别的路由/页面时也能找回来。

:::warning 注意
元素选择依赖 `unplugin-vue-inspector`（插件已内置），仅对 Vue 组件有效。纯 HTML 元素选中后 `filePath` 可能为空，AI 会通过 Chrome DevTools 工具自行定位。
:::

## 浏览器控制（Chrome 远程调试）

当 AI 需要直接操作你的浏览器页面——截图、点击元素、读取控制台与网络请求、切换/导航页面等（`chrome-devtools_*` 工具）时，插件通过 **Chrome 远程调试**（CDP）连接你正在使用的浏览器。插件启动时会默认预热该连接（`warmupChromeMcp`，默认开启），连接失败时面板会提示 **「Chrome DevTools MCP 连接失败」**。

按以下步骤开启后重试：

1. 在 Chrome 地址栏输入 `chrome://inspect/#remote-debugging` 并回车
2. 勾选 **Allow remote debugging for this browser instance** 选项
3. 重新启动浏览器
4. 回到面板点击 **重试连接**（或重启 `vite dev`）

:::tip
- 连接成功后无需手动传页面 ID：面板会自动定位你当前浏览的本地页面。
- 不使用浏览器操作类能力时，可关闭启动预热避免连接提示：`warmupChromeMcp: false`。
- 使用自定义调试端口启动 Chrome 时，请同步配置 `chromeDevtoolsPort`（默认 9222），详见「配置项」章节。
:::

## 审查面板与诊断

- **代码审查面板**：若所选引擎支持（默认的 OpenCode 引擎支持），面板 Header 会出现 **`</>`** 按钮，点击展开 / 收起 AI 对代码修改的审查结果。该按钮仅当引擎声明支持审查能力时显示，例如 DeepSeek Harness (dsh) 引擎不展示，避免出现无功能的入口。
- **代码诊断**：两个引擎都提供诊断工具（如 `run_diagnostics`），AI 可主动运行 ESLint / vue-tsc 检查并把结果并入对话，无需离开面板。

## 主题切换

侧边栏支持三种主题模式，点击面板 Header 中的主题按钮即可切换：

- **亮色** — 适合明亮环境
- **暗色** — 适合夜间使用
- **自动** — 跟随系统主题自动切换

## 快捷键速查

| 快捷键         | 功能                    |
| -------------- | ----------------------- |
| `Ctrl/Cmd + K` | 打开 / 关闭侧边栏       |
| `Ctrl/Cmd + P` | 进入 / 退出元素选择模式 |
| `ESC`          | 退出选择模式            |

快捷键 `Ctrl/Cmd + K` 可在插件配置中自定义，详见「配置项」章节。

## 多项目支持

同时打开多个不同项目的 `localhost` 页面：

- 每个项目的页面地址（host + 端口）会被识别为独立项目
- 切换标签页时，侧边栏自动切换到对应项目的 AI 会话与上下文
- 各项目的会话、选中元素互不干扰

## 无服务状态

如果侧边栏提示未检测到 AIPanel 服务，按以下顺序排查：

1. **确认 AI 引擎已安装**（与你配置的 `provider` 一致）：
   - OpenCode：`opencode --version`
   - DeepSeek Harness：`dsh --version`，并确认已安装 `@aipanel/provider-deepseek`
2. 确认项目的 Vite 开发服务器正在运行（`npm run dev`），且日志中没有报错
3. 确认当前页面是 `localhost` 地址（插件仅对本地开发页面生效）
4. 重启开发服务器后重新打开侧边栏

若仍未解决，参见「常见问题」。
