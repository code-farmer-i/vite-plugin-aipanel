# 使用指南

## 打开对话面板

用 Chrome 打开 `localhost` 开发页面后，有两种方式打开侧边栏：

1. 点击浏览器工具栏中的 **OpenCode 图标**
2. 使用快捷键（默认 **`Ctrl/Cmd + K`**，可在 Vite 插件配置中修改）

侧边栏弹出后自动连接到当前项目的 OpenCode 服务，直接在对话框中输入指令即可。

## 会话管理

侧边栏左侧显示当前项目的会话列表：

- **自动复用** — 同一项目自动恢复上次会话
- **新建会话** — 点击 + 号创建新对话
- **切换会话** — 点击会话列表中的历史记录
- **删除会话** — 右键删除不再需要的会话

多个项目同时打开时，切换浏览器标签页会自动切换到对应项目的会话。

## 页面上下文同步

打开面板后，以下信息自动实时同步给 AI：

| 信息       | 同步时机               |
| ---------- | ---------------------- |
| 页面 URL   | 页面加载、SPA 路由切换 |
| 页面标题   | `document.title` 变化  |
| 标签页切换 | 切换浏览器标签页时     |

无需手动描述当前在哪个页面，AI 自动知晓上下文。

## 元素选择器

想告诉 AI "改这个按钮的颜色"，不用描述它的位置，直接选中就行。

### 使用方法

1. 按 **`Ctrl/Cmd + P`** 进入选择模式
2. 鼠标悬停时，页面元素会高亮显示
3. 点击目标元素，组件源码位置自动传给 AI
4. 按 **`ESC`** 退出选择模式

### 传给 AI 的信息

- 组件源码文件路径和行号
- 元素文本内容
- 元素的 HTML 描述

AI 收到这些信息后可以直接定位到对应代码，精准修改。

:::warning 注意
元素选择依赖 `unplugin-vue-inspector`（Vite 插件已内置），仅对 Vue 组件有效。纯 HTML 元素选中后 `filePath` 可能为空，AI 会通过 Chrome DevTools 工具自行定位。
:::

## 主题切换

侧边栏支持三种主题模式：

- **亮色** — 适合明亮环境
- **暗色** — 适合夜间使用
- **自动** — 跟随系统主题自动切换

点击侧边栏 Header 中的主题按钮即可切换。

## 快捷键速查

| 快捷键         | 功能                    |
| -------------- | ----------------------- |
| `Ctrl/Cmd + K` | 打开 / 关闭侧边栏       |
| `Ctrl/Cmd + P` | 进入 / 退出元素选择模式 |
| `ESC`          | 退出选择模式            |

快捷键 `Ctrl/Cmd + K` 可在 Vite 插件配置中自定义，详见 [配置项](guide/config)。

## 多项目支持

同时打开多个不同项目的 `localhost` 页面：

- 切换标签页时，侧边栏自动切换到对应项目的 AI 会话
- 每个项目的上下文独立管理
- 无需手动切换项目

## 无服务状态

如果当前页面没有检测到 OpenCode 服务，侧边栏会显示提示页面，引导你：

1. 确认已安装 OpenCode CLI（`opencode --version`）
2. 启动项目的 Vite 开发服务器（`npm run dev`）
3. 确认当前页面是 `localhost` 地址（插件仅对本地开发页面生效）
