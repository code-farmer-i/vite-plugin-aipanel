# AI 对话面板

## 基本操作

### 打开 / 关闭面板

- **点击悬浮按钮**：页面右下角的圆形按钮，点击展开面板
- **快捷键**：默认 `Ctrl + K`（macOS 用 `Cmd + K`），可按配置修改
- **ESC 键**：关闭面板（非选择模式下）

### 面板布局

```
┌──────────────────────────────────────────────────┐
│  Header: 会话标题 | 主题切换 | 新建/最小化/关闭     │
├──────────────────────────────────────────────────┤
│  Frame: OpenCode Web (iframe)                    │
│  ┌────────────────────────────────────────────┐  │
│  │  左侧: 会话列表 (可折叠)                     │  │
│  │  右侧: AI 对话区域                           │  │
│  │  - 聊天消息                                  │  │
│  │  - 推理摘要 (如果开启 showReasoningSummaries) │  │
│  │  - 工具调用 (文件编辑、命令执行等)             │  │
│  │  - 输入框                                    │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

### 主题切换

面板主题与 OpenCode Web 内部主题实时同步：

- **Auto**：跟随系统
- **Light**：浅色模式
- **Dark**：深色模式

切换方式：
- 面板 Header 的月亮/太阳图标
- OpenCode Web 内部的设置面板

## 悬浮按钮

按钮支持：
- **拖拽定位**：长按拖动到页面任意位置
- **边缘磁吸**：靠近页面边缘时自动吸附

## 通知提示

面板会在以下场景显示通知提示（3000ms 自动消失）：

- 会话创建成功/失败
- 会话删除成功/失败
- 元素选择成功/失败
- Chrome MCP 预热成功/失败
- 服务启动失败

## 快捷键汇总

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + K` | 切换面板 | 默认配置，可自定义 |
| `Ctrl/Cmd + P` | 切换元素选择模式 | 非扩展模式有效 |
| `ESC` | 退出选择模式 / 关闭面板 | 选择模式优先 |
