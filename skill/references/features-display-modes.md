# 展示模式

## 四种模式

### Bubble 模式（默认）

```
┌──────────────────────────────────────┐
│  用户页面                            │
│                                      │
│                              ┌─────┐ │
│                              │ 💬  │ │  ← 悬浮按钮
│                              └─────┘ │
│  点击展开:                            │
│  ┌─────────────────────────┐        │
│  │ Header                  │        │
│  ├─────────────────────────┤        │
│  │ 会话列表 │ AI 对话区域    │        │
│  │          │              │        │
│  └─────────────────────────┘        │
└──────────────────────────────────────┘
```

- 右下角悬浮按钮，不影响页面布局
- 点击展开浮动面板
- 按钮可拖拽，支持边缘磁吸

### Split 模式

```
┌──────────────────────┬───────────────┐
│  用户页面（收缩后）    │ Header        │
│                      ├───────────────┤
│                      │ 会话列表       │
│  ← 可拖拽 ←          │               │
│                      │ AI 对话区域    │
│                      │               │
│                      │ 输入框         │
└──────────────────────┴───────────────┘
```

- 面板固定在页面右侧（可配置左侧）
- 主页面内容自动收缩
- 分隔线可拖拽调整宽度（400-800px）
- 适合需要持续查看 AI 对话的场景

### Auto 模式

面板内提供模式切换按钮，用户可随时在 bubble/split/auto 之间自由切换，无需修改配置重启。

### Extension 模式

利用浏览器扩展的独立侧边栏：

- 面板在扩展侧边栏中显示
- 页面悬浮按钮隐藏（`hideBubble: true`）
- 通过扩展的 Content Script 与页面通信
- 支持多 Tab 多实例隔离

## 分屏模式配置

```ts
opencodeAssistant({
  displayMode: "split",
  splitMode: {
    width: 500,              // 默认宽度
    minWidth: 400,           // 最小宽度（拖拽限制）
    maxWidth: 800,           // 最大宽度（拖拽限制）
    resizable: true,         // 是否允许拖拽调整
    shrinkPage: true,        // 是否收缩主页面
    defaultOpen: true,       // 默认展开
    position: "right",       // left | right
  },
});
```

### 拖拽调整

- 鼠标悬停在分隔线上时变为拖拽光标
- 拖拽实时调整面板宽度
- 受 `minWidth` / `maxWidth` 限制

### 分屏模式下的选择模式

- 进入选择模式时面板**不关闭**（与 Bubble 模式不同）
- 选中元素后面板保持可见
