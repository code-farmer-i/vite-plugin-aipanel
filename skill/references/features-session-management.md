# 会话管理

## 会话机制

OpenCode 以项目为单位管理会话。插件会自动：

1. 启动时检查当前项目是否已有会话
2. 有则自动复用，没有则创建新会话
3. 会话 URL 通过代理服务生成，格式为 `http://{hostname}:{proxyPort}/{base64(projectDir)}/session/{sessionId}`

## 会话列表

面板左侧显示当前项目的所有会话：

- **会话标题**：首次创建显示"新会话"，OpenCode 会自动生成标题
- **思考状态**：显示会话是否正在处理中（思考指示器）
- **排序**：按更新时间倒序

### 过滤规则

会话列表会自动过滤以下会话：
- `__chrome_mcp_warmup__` - Chrome MCP 预热专用会话
- 有 `parentID` 的 - Subagent 子会话
- 已归档的会话

## 操作

### 创建会话

- 点击面板 Header 的"+"按钮
- 或：首次打开面板且无现有会话时自动创建

### 切换会话

点击列表中的会话即可切换。切换到不同会话时 iframe 会重新加载对应会话页面。

### 删除会话

点击会话右侧的删除按钮。删除后的行为：
- 如果还有剩余会话，切换到第一个
- 如果没有剩余会话，自动创建新会话

## AI 思考状态

每个会话有三种状态：

| 状态 | 说明 | 指示器表现 |
|------|------|------------|
| `idle` | 空闲，等待输入 | 无指示 |
| `running` | AI 正在执行任务 | 思考动画 |
| `streaming` | AI 正在输出回复 | 思考动画 |
| `completed` | 任务完成 | 无指示 |

**任一**会话处于 `running` 或 `streaming` 状态时，整个面板的 `thinking` 状态为 `true`（全局思考指示器）。
